      Marantz

      Für Fernbedienung und „Auf dem Marantz abspielen“. Die Adresse wird aus den Abrufen erkannt; trage sie nur ein, wenn sie nicht stimmt. Im Marantz muss „Netzwerk-Standby“ eingeschaltet sein, damit er sich aus dem Standby wecken lässt.

      Auf dem iPhone als App

      In Safari diese Seite öffnen, unten auf Teilen tippen und Zum Home-Bildschirm wählen. YCast startet dann im Vollbild mit eigenem Symbol. Beim ersten Start einmal mit dem Umbrel-Passwort anmelden.

      Netzwerk

      Der Receiver-Dienst braucht eine eigene, freie IP in deinem Heimnetz (Port 80). Wähle eine Adresse außerhalb des DHCP-Bereichs deines Routers. Adapter, Netz und Gateway erkennt die App beim Start selbst.

      DNS über Pi-hole

      Der Marantz fragt denon.vtuner.com ab. Deine Pi-holes müssen diesen Namen auf – umleiten.

      1. Pi-hole 6 öffnen → Settings → Local DNS Records.
      2. Zwei Einträge anlegen, jeweils mit der IP –:
        denon.vtuner.comdenon2.vtuner.com
      3. Auf jedem Pi-hole wiederholen.
      4. Der Marantz muss einen Pi-hole als DNS nutzen (per DHCP der Fritzbox oder fest im Receiver). Danach den Marantz einmal komplett stromlos machen.
      Alternative: alle *.vtuner.com umleiten (nicht über die Weboberfläche möglich)

      Pi-hole direkt installiert, per SSH:

      sudo pihole-FTL --config misc.dnsmasq_lines '["address=/vtuner.com/–"]'

      Pi-hole im Docker-Container, als Umgebungsvariable (danach Container neu starten):

      FTLCONF_misc_dnsmasq_lines: 'address=/vtuner.com/–'
