Broker: Alpaca (Paper)

nicht verbunden
  1. Kostenlos registrieren auf alpaca.markets (nur E-Mail).
  2. Im Dashboard oben links auf Paper wechseln → API Keys → Generate New Keys.
  3. Key ID und Secret hier eintragen. Sie werden geprüft und nur auf dem Umbrel gespeichert.

Nur Paper-Trading: Die App spricht ausschließlich mit paper-api.alpaca.markets. Live-Handel ist nicht freigeschaltet.
